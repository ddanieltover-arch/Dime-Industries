## GEO writing rules (every brief)

1. Write **Quick Answer** (40–60 words) first — body starts with `Quick Answer:`
2. Question-format H2s; include FAQ block when PAA-heavy
3. Prefer tables / ordered steps over prose walls
4. Link cluster: shop hub + glossary/trust + Validate/Lab Results where relevant
5. Compliance: educational only; 21+ / licensed markets; no medical claims
6. Schema: BlogPosting + FAQPage and/or HowTo as applicable
