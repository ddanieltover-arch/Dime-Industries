# Link Quality Standards (Section 9.5)

Count a link as a **win** only if **all** of the following are true:

1. **Domain Rating ≥ 30** (Ahrefs DR or Moz DA equivalent)
2. **Editorial context** — human-readable article, guide, show notes, or news — not directory spam, comment spam, or PBNs
3. **Topically relevant** — cannabis, licensed retail, hardware education, CA/MA local, or coin-fact GEO (for the dime-roll post only)
4. **Dofollow** *or* high-authority **nofollow** (e.g. major news) that still delivers brand/AI citation value
5. **Real organic traffic** — Ahrefs traffic estimate **> 100 visits/month** (or clear brand SERP presence)

## Do not count as wins

- Paid link farms / PBNs / expired-domain networks
- Unmoderated profile/wiki spam
- Irrelevant foreign gambling/pharma blasts
- Links to staging / Vercel preview URLs
- Links acquired via black-hat automation

## Attribution URL rules

- Prefer `https://www.dimeindustries.us/...`
- If an editor insists on legacy `.com`, request a second pass to update after cutover — track as `Pending URL migration` in CRM
